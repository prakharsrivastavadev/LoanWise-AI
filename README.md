# LoanWise AI

A modern AI-powered loan and EMI calculator built with Python, Streamlit, Pandas, and Plotly.

## Features

- 💳 EMI Calculator
- 📅 Loan Repayment Schedule
- 📈 Amortization Table
- 💰 Total Interest Calculator
- 📊 Interactive Charts
- 📤 CSV Export
- ⚡ Fast and Simple Interface

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
