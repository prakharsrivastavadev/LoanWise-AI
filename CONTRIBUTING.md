# Contributing to LoanWise AI

Thank you for your interest in contributing to LoanWise AI.

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/your-username/LoanWise-AI.git
```

3. Navigate to the project.

```bash
cd LoanWise-AI
```

4. Install the required dependencies.

```bash
pip install -r requirements.txt
```

5. Run the application.

```bash
streamlit run app.py
```

---

## Development Guidelines

- Follow PEP 8 coding standards.
- Keep code modular and readable.
- Write descriptive variable and function names.
- Test new features before submitting.
- Update documentation when necessary.

---

## Pull Requests

Before submitting a pull request:

- Ensure the project runs successfully.
- Verify existing functionality is not broken.
- Keep pull requests focused on a single feature or fix.
- Update documentation if applicable.

---

## Reporting Bugs

Please include:

- Operating System
- Python Version
- Streamlit Version
- Steps to Reproduce
- Expected Behavior
- Actual Behavior
- Screenshots (if applicable)

---

## Feature Requests

Feature requests are welcome.

Please describe:

- The problem.
- Your proposed solution.
- Expected benefits.
- Alternative approaches considered.

---

## Questions

If you have any questions, feel free to open a GitHub Issue.
