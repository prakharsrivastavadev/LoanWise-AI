# Security Policy

## Supported Versions

The following versions currently receive security updates.

| Version | Supported |
|----------|-----------|
| 1.x | ✅ Yes |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public GitHub Issue.

Instead, provide:

- A clear description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Potential impact
- Screenshots or logs (if available)

Security reports will be reviewed and addressed as quickly as possible.

---

## Security Best Practices

- Keep Python and project dependencies up to date.
- Do not commit API keys or secrets.
- Do not upload personal financial data.
- Use trusted package sources only.
- Review dependencies regularly for security updates.

---

## Out of Scope

The following are generally **not** considered security issues:

- Typographical errors
- UI or design suggestions
- Feature requests
- Documentation improvements
- Performance optimizations

---

## Responsible Disclosure

Please report security issues responsibly and allow time for investigation before public disclosure.

Thank you for helping improve the security of LoanWise AI.
